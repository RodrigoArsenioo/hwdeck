HW Deck
=======

A small dashboard for HWiNFO.

Setup
1. Install HWiNFO (hwinfo.com) and turn on Shared Memory Support in its settings.
2. Keep this folder together and run HWDeck.exe.
3. If Windows says it protected your PC: More info, then Run anyway (the app isn't signed).

Good to know
- Closing the window keeps it in the tray. Right-click the tray icon to quit.
- The free HWiNFO stops sharing after 12 hours. HW Deck then offers to restart it. Keep HWiNFO sharing in Settings does that for you before it stops.
- It asks GitHub once a day if there's a new version (Settings can turn that off). Nothing else goes online.
- To update: quit it from the tray, unzip the new version over this folder.
- Your data is in %APPDATA%\HW Deck. To remove the app, turn off Start with Windows in its settings, quit it, then delete this folder and that one.
